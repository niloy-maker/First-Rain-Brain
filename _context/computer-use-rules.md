# What Claude may and may not do via Computer Use (GA Q2 2026).

## Allowed (read-only)
- Read Zoho Books dashboard: operating cash, receivables balance
- Read Zoho Bigin pipeline: view only — no edits
- Navigate Notion to read project task status
- Open Gmail threads to read status updates

## Not allowed — ever
- Any transaction, payment, or transfer
- Editing any CRM record (Bigin, Zoho Books)
- Sending emails, messages, or notifications without Niloy approval
- Accessing banking or payment portals

## Approval required before
- Any action that modifies a record
- Any action that sends a communication
- Any action that cannot be reversed
