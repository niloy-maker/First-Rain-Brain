## Ask first
"What needs stress-testing?"

## Run the 5-point decision filter
1. Does this protect contribution margin?
2. Does this reduce Secure Meters concentration?
3. Does this reduce single-point dependencies?
4. Does this increase system resilience?
5. Does this strengthen enterprise positioning?

3+ No → flag and do not proceed. State exactly which checks failed and why.

## Rules
- Push back on anything that compromises the 33% floor
- Push back on anything that increases Secure concentration
- Push back on anything that treats verbal as revenue (Elliott Ebara rule)
- Be direct. Do not validate poor financial decisions.
- If the decision passes all 5 — say so clearly and state why.
